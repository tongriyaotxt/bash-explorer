对象是 **ShellItem**，不是"路径"——所以「此电脑」「回收站」「控制面板」和盘符是同一类东西。

---

## 为什么是 TUI，不是嵌 WT

WT 的渲染绑在自己的顶层 HWND 上，`SetParent` 之后窗口在、内容不画（实测过）。
所以不嵌它，**直接活在它里面**：一个全屏控制台程序，用 ANSI 自己排版。

拿到的好处：WT 的字体、配色、分屏、滚动、复制粘贴、字体回退，全部免费。

---

## 启动

```
xs                 在当前目录启动（在 WT 里跑就是 WT 的样子）
xsw                用 Windows Terminal 打开，起点是当前目录
xs D:\项目          指定起始目录
xs -c "ls"         批量模式：跑一条命令就退出（不占屏、去色）
xs -f cmds.txt     跑命令文件，# 开头是注释
```

## 键位

| 键 | 作用 |
|---|---|
| `Tab` | 补全当前词；有多个候选时把候选打在状态行 |
| `↑` `↓` | 命令行空着时：移动列表光标；有内容时：翻历史 |
| `Enter` | 命令行空着时：打开光标项（目录进入 / 文件用默认程序）；否则执行命令 |
| `Backspace` | 命令行空着时：上一级目录；否则删字符 |
| `PageUp/Down` `Home/End` | 翻页 / 跳首尾 |
| `Ctrl+A/E/U/K/W` | 行首/行尾/删到行首/删到行尾/删一个词 |
| `Ctrl+C` | 清空命令行 |
| `Ctrl+Q` | 退出 |

中文按**显示宽度**算列宽和光标位置，不会错位。

## 命令

`ls` `ll` `cd` `pwd` `up` `back` `mkdir` `rm [-r][-f]` `cp` `mv` `open` `info` `find` `roots` `help` `exit`

- `ls` / `ll` 在 TUI 里切换简表 / 明细（明细多出「类型」列和秒级时间）
- `cd` 接受四类目标：文件系统路径、`::{GUID}`、**子项显示名**（`cd "OS (C:)"`）、`shell:` 前缀
- `roots` 把命名空间根列成一张可选列表（回车就进）
- `find` 把结果列表替换成搜索结果（`cd`/`up` 回到目录视图）
- `cp`/`mv`：文件系统走 .NET；虚拟命名空间走 Shell 的 `CopyHere`/`MoveHere`

## 这轮修掉的两个真 bug

1. **特殊键收不到**。在某些宿主里 `Console.ReadKey` 把回车/退格当**控制字符**返回
   （`KeyChar='\r'`、`'\u007f'`，`Key=0`），被"可打印字符"分支挡掉了——
   表现为：能打字，但回车不执行、退格不删。
   修法：显式关掉 stdin 的 `ENABLE_VIRTUAL_TERMINAL_INPUT`，并对 `KeyChar` 做回退判断。
2. **反显没复位**。`C_OFF` 被我写成了空串，`ESC[7m` 之后没有 `ESC[0m`，
   整个列表都被涂成高亮。修法：`C_OFF = ESC + "[0m"`。

`xsw` 也加固了：exe 不存在 / 目录不存在都会**在当前窗口报错并 pause**，
不会闪一下就没了；还顺带修了「旧实例占着 exe 导致编译/重启失败」的问题。

## 与另外两个工具的关系

| | 操作对象 | 界面 | 方向 |
|---|---|---|---|
| **xs** | ShellItem | 终端 TUI | 全键盘，自带渲染 |
| **xc** | 真资源管理器窗口 | 资源管理器 | 命令驱动它的导航/选中 |
| **xf** | 选区 → bash | 终端 | 把选中项喂给 bash |

## 回滚

```powershell
Remove-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\xs.cmd"
Remove-Item "$env:LOCALAPPDATA\Microsoft\WindowsApps\xsw.cmd"
```

程序本体在 `D:\项目\闲扯\explorer-bash\xs\`，删目录即可。
**不写注册表、不起服务、不改 PATH**。
